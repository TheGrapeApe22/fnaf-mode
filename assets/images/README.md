Put your still Mangle pictures here: PNG, JPG/JPEG, or WebP.
Each file is one randomly selectable visual. Prefer screen-sized images.
Include top, bottom, left, or right in the filename to align to screen edges.
Combine them for corners: mangle-top-left.png or mangle_bottom_right.png.
Hints are case-insensitive substrings. No hint (or center/centre) means centered.
Images keep their proportions and fit inside the screen without cropping.
Set audio in ../audio_links.json under "images", using the filename without its
extension as the key and an array of filenames from ../sounds/ as the value.
